# Jurnal Guru Enterprise

**Jurnal Guru Enterprise** adalah Sistem Informasi Manajemen Pembelajaran dan Supervisi Akademik berbasis web yang dirancang untuk mendukung operasional kegiatan belajar mengajar (KBM) di **MA Darul Faqih Indonesia**.

Sistem ini mengintegrasikan pengisian jurnal harian guru, presensi kehadiran siswa, manajemen perangkat ajar, penilaian hasil belajar, hingga modul **Supervisi Akademik** untuk Kepala Madrasah dan Waka Kurikulum secara terpadu.

---

## 📌 Garis Besar Fitur Aplikasi

- **📘 Jurnal Pembelajaran & Presensi Siswa**  
  Pencatatan agenda mengajar harian guru, jam pelajaran, dan rekapitulasi presensi siswa secara real-time.

- **📋 Supervisi Akademik Digital**  
  Pelaksanaan supervisi akademik terhadap guru menggunakan dokumen instrumen baku (Form 1 s.d. Form 4) dengan fitur perhitungan nilai otomatis, live timer observasi kelas, serta ekspor laporan PDF/Excel resmi.

- **📁 Manajemen Perangkat Ajar**  
  Unggah dan verifikasi dokumen administrasi pembelajaran (RPP / Modul Ajar) oleh Waka Kurikulum.

- **📊 Dashboard Multi-Role**  
  Tampilan dashboard terpisah yang disesuaikan untuk Kepala Madrasah, Waka Kurikulum, Admin, Guru, dan Wali Kelas.

- **📈 Penilaian & Monitoring KBM**  
  Pencatatan nilai harian, ujian, keaktifan siswa, serta monitoring ketercapaian target kurikulum.

---

## 👥 Pengguna & Hak Akses

- **Administrator / Super Admin**: Pengelolaan master data, sistem, dan konfigurasi.
- **Kepala Madrasah**: Monitoring KBM dan pelaksanaan supervisi akademik guru.
- **Waka Kurikulum**: Verifikasi perangkat ajar, monitoring KBM, dan supervisi akademik.
- **Guru Mata Pelajaran**: Pengisian jurnal mengajar, presensi, penilaian, unggah perangkat ajar, dan melihat hasil supervisi.
- **Wali Kelas**: Monitoring kehadiran dan aktivitas siswa kelas binaan.

---

## 🛠️ Teknologi Utama

- **Backend**: CodeIgniter 3 (PHP 8.x)
- **Database**: MySQL / MariaDB
- **Frontend**: HTML5, Vanilla CSS, Bootstrap 5, Tabler Framework, JavaScript (jQuery)
- **Laporan & Ekspor**: Dompdf (PDF) & PhpOffice/PhpSpreadsheet (Excel)
